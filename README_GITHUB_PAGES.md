# Orlando Custom Tees | Demonstração do site

**Esta pasta é apenas uma prévia estática**, pronta para GitHub Pages. Inclui as páginas HTML, estilos CSS, JavaScript e imagens, com `index.html` na raiz.

## Como publicar
1. Crie um repositório público novo no GitHub (por exemplo `oct-website-preview`).
2. Clique **Add file > Upload files** e arraste **o conteúdo desta pasta** (não a pasta contendo todos os arquivos). Confirme **Commit changes**.
3. Em **Settings > Pages > Build and deployment**, selecione **Deploy from a branch**.
4. Selecione **main / (root)** e salve.
5. O endereço será `https://SEU-USUARIO.github.io/oct-website-preview/`.

O GitHub Pages é gratuito para repositórios públicos no plano GitHub Free e somente publica arquivos estáticos. Nesta versão, o envio de orçamento está propositalmente **desativado**. **Não** publique segredos, senhas, documentos de clientes ou arquivos da pasta `api` em um repositório público.

O site atual `orlandocustomtees.com` não é afetado por este teste. Para colocar o novo site em produção com o formulário funcionando, será preciso usar hospedagem que execute PHP ou conectar uma API segura ao CRM existente.
