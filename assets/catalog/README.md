# Orlando Custom Tees official garment photos

Images published for website and quote-system previews. Seven models, 243 model/color combinations. 594 garment photographs, 2 brand photographs.

Optimized WebP thumbnails are 720x900 pixels maximum. The high-resolution JPG originals are preserved in Orlando Custom Tees project library.

The JSON maps garment styles, colors and available front/back views. All paths under `Fotos/` and `Marcas/` are relative to `assets/catalog/`.

Product photographs and colors are visual references. Stock, supplier costs and availability must be checked separately.
